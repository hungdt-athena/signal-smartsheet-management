⚠️ Hard rules

What each conclusion means & when to pick it

The Initial Conclusion dropdown has exactly three options. Link_dead is not one of them: it is set with the Dead link toggle at the top of the block:

OptionPick it whenWhat happens next
Bypass The game doesn't make the cut and isn't worth following. The game leaves the pipeline and is marked done.
List_Idea The game has potential and you want to keep it. It auto-joins the weekly batch → appears in the Short List for the mod to finalize (see step 7).
Playtest & Bypass Not a keeper, but worth playing through once before dropping it. Playtest it, then drop it. The game is marked done and never joins a batch.
Dead link (toggle) The store link is broken / unreachable. Sets the status to Link_dead and marks done, no further evaluation needed.
⚠️

A game only counts as “done” once you've picked a Conclusion. Filling in just the Note leaves it Pending. Once you set the conclusion, the system records the Evaluated date automatically.

Demo Video: filled in from the file name

The Demo Video (Drive) field has a flow running every hour: it scans the Drive video folder, strips the file extension and compares the file name to the game name. On a match the link lands in this field by itself.

File name on Drive
Block Blast Saga.mp4match
Game name in the app
Block Blast Saga
Demo Video (Drive)
https://drive.google.com/file/d/1a2B.../viewauto-filled

Same name as the game and the link comes back on its own; one character off and it misses

  • Name the file exactly like the game, apart from the .mp4 extension. Upper or lower case doesn't matter, everything else must match.
  • Check back after about an hour. An empty Demo Video field means the name didn't match.
  • No match? Paste it yourself. Drop the Drive link straight into the Demo Video field, or use “+ Import” in the Demo Video column of the table.
⚠️

The flow only fills the field while it is empty. If you pasted a wrong link by hand, the flow will not overwrite it and you have to fix that link yourself.

The Note is required

A note needs at least 10 characters. Below that, Save is blocked and an orange counter appears under the Note box:

This applies to every save, not just while you're writing the note. Reopening an old game with an empty note, even to change a different field, is blocked until you write one. Only Dead link is exempt: a broken link leaves nothing to write about.

Where to check your own tags

Tracking your own work

Two places in Team Operations let you look back at what you've done:

  • Performance: your working stats. You only see your own, never anyone else's.
  • Assign: the roster and the history of games assigned to you: which round, how many games, on what date.
💡

These two screens are for your own tracking, and the metrics shown there change over time: open them rather than memorising them. If something doesn't match how your month actually went, tell your manager.
